# 数据表设计

## 1. SQLITE 特点

1. 字符类型是 TEXT, 虽然支持 VARCHAR 但是长度约束无效，且本质上会转化为 TEXT

## 2. 详细数据库设计

配置文件表 config

1. [废弃]~~配置文件表 (config)~~

   | 字段  | SQLite 类型 | 约束                      | 默认值 | 备注     |
      | ----- | ----------- | ------------------------- | ------ | -------- |
   | id    | INTEGER     | PRIMARY KEY AUTOINCREMENT |        | 主键     |
   | name  | TEXT        | UNIQUE NOT NULL           |        | 配置项名 |
   | value | TEXT        | NOT NULL                  |        | 配置值   |

   建议配置项：

    ```sql
    INSERT INTO config (name, value) VALUES 
    ('root_path', '/data'),         -- 根目录路径
    ('calc_hash', '1'),             -- 是否计算文件哈希
    ('max_archive_size', '1073741824'), -- 最大存档大小 (1GB)
    ('archive_path', '/data/archive/'),  -- 存档目录路径)
    ```

    - 使用 JSON 文件代替

2. 根目录索引 root_index

   存档的时候，需要把根目录写入索引表; 解档的时候，需要从索引表中选取需要解档的根目录。

   | 字段       | 类型    | 约束                      | 默认值            | 备注                  |
      | ---------- | ------- | ------------------------- | ----------------- | --------------------- |
   | id         | INTEGER | PRIMARY KEY AUTOINCREMENT |                   | 目录唯一标识          |
   | root_path  | TEXT    | NOT NULL   UNIQUE         |                   | 根目录                |
   | status     | TEXT    | NOT NULL                  | 'HEALTH'          | 状态：HEALTH/RECYCLED |
   | created_at | INTEGER | NOT NULL                  | CURRENT_TIMESTAMP | 创建时间戳            |
   | updated_at | INTEGER | NOT NULL                  | CURRENT_TIMESTAMP | 更新时间戳            |

3. 目录索引表 directory_index

   | 字段            | 类型    | 约束                               | 默认值            | 备注                   |
      | --------------- | ------- | ---------------------------------- | ----------------- | ---------------------- |
   | id              | INTEGER | PRIMARY KEY AUTOINCREMENT          |                   | 目录唯一标识           |
   | root_id         | INTEGER | NOT NULL REFERENCES root_index(id) |                   | 目录根目录             |
   | directory_name  | TEXT    | NOT NULL                           | ''                | 目录名                 |
   | directory_mtime | INTEGER | NOT NULL                           | 0                 | 修改时间 (unix 时间戳) |
   | directory_path  | TEXT    |                                    |                   | 相对路径               |
   | status          | TEXT    | NOT NULL                           | 'HEALTH'          | 状态：HEALTH/RECYCLED  |
   | created_at      | INTEGER | NOT NULL                           | CURRENT_TIMESTAMP | 创建时间戳             |
   | updated_at      | INTEGER | NOT NULL                           | CURRENT_TIMESTAMP | 更新时间戳             |

    - unique(root_id, directory_path)

4. [Optional]目录树关系表 - 闭包表 (directory_tree)

   | 字段          | 类型    | 约束                                    | 默认值            | 备注                       |
      | :------------ | :------ | :-------------------------------------- | ----------------- | :------------------------- |
   | ancestor_id   | INTEGER | NOT NULL REFERENCES directory_index(id) |                   | 祖先目录 ID                |
   | descendant_id | INTEGER | NOT NULL REFERENCES directory_index(id) |                   | 后代目录 ID                |
   | depth         | INTEGER | NOT NULL                                |                   | 目录层级深度（0 表示自身） |
   | status        | TEXT    | NOT NULL                                | 'HEALTH'          | 状态：HEALTH/RECYCLED      |
   | created_at    | INTEGER | NOT NULL                                | CURRENT_TIMESTAMP | 创建时间戳                 |
   | updated_at    | INTEGER | NOT NULL                                | CURRENT_TIMESTAMP | 更新时间戳                 |

5. 文件索引表 file_index

    - 硬链接所指的文件，和源文件仅路径和名称存在差异，hash，修改日期等都一致
    - 文件索引表中仅文件信息相关内容, 不要有存档相关信息, 和存档解耦, 存档相关数据表单向引用文件索引表的内容

   | 字段         | 类型    | 约束                                    | 默认值            | 备注                                                    |
      | :----------- | :------ | :-------------------------------------- | :---------------- | :------------------------------------------------------ |
   | id           | INTEGER | PRIMARY KEY AUTOINCREMENT               |                   | 文件唯一标识                                            |
   | directory_id | INTEGER | NOT NULL REFERENCES directory_index(id) |                   |                                                         |
   | file_name    | TEXT    | NOT NULL                                |                   | 文件名 (不含路径)                                       |
   | file_size    | INTEGER | NOT NULL                                | 0                 | 文件大小 (字节)                                         |
   | file_mtime   | INTEGER | NOT NULL                                | 0                 | 修改时间 (unix 时间戳)                                  |
   | file_hash    | TEXT    |                                         |                   | hash/SHA256哈希值(可重复, 当文件内容相同，文件名不同时) |
   | volume_count | INTEGER |                                         |                   | 分卷数量(此处存在耦合, 没存档为 null)                   |
   | status       | TEXT    | NOT NULL                                | 'HEALTH'          | 状态：HEALTH/RECYCLED                                   |
   | created_at   | INTEGER | NOT NULL                                | CURRENT_TIMESTAMP | 创建时间戳                                              |
   | updated_at   | INTEGER | NOT NULL                                | CURRENT_TIMESTAMP | 更新时间戳                                              |

    - UNIQUE (directory_id, file_name, file_hash)

6. 存档元数据表 (archive_metadata)

   | 字段                 | 类型    | 约束                      | 默认值            | 备注                                  |
      | -------------------- | ------- | ------------------------- | ----------------- | ------------------------------------- |
   | id                   | INTEGER | PRIMARY KEY AUTOINCREMENT |                   | 存档 ID                               |
   | name                 | TEXT    | UNIQUE NOT NULL           |                   | 存档名称                              |
   | archive_limit_size   | INTEGER | NOT NULL                  |                   | 存档限制大小（字节）                  |
   | archive_hash         | TEXT    |                           |                   | 存档文件的 hash 校验值                |
   | is_compressed        | INTEGER | NOT NULL                  | 0                 | 0=未压缩，1=已压缩                    |
   | compressed_algorithm | TEXT    |                           |                   | 压缩算法（如 gzip/zstd）              |
   | is_encrypted         | INTEGER | NOT NULL                  | 0                 | 0=未加密，1=已加密                    |
   | encryption_algorithm | TEXT    |                           |                   | 加密算法（如 aes-256-cbc）            |
   | status               | TEXT    | NOT NULL                  | 'HEALTH'          | 状态（HEALTH/RECYCLED/HASH_OUTDATED） |
   | created_at           | INTEGER | NOT NULL                  | CURRENT_TIMESTAMP | 创建时间戳                            |
   | updated_at           | INTEGER | NOT NULL                  | CURRENT_TIMESTAMP | 更新时间戳                            |

7. 存档内容表 (archive_asset)

   | 字段          | 类型    | 约束                                     | 默认值            | 备注                                                      |
      | :------------ | :------ | :--------------------------------------- | :---------------- | :-------------------------------------------------------- |
   | id            | INTEGER | PRIMARY KEY AUTOINCREMENT                |                   | 存档资源唯一标识                                          |
   | archive_id    | INTEGER | NOT NULL REFERENCES archive_metadata(id) |                   | 关联的存档 ID                                             |
   | asset_name    | TEXT    | NOT NULL UNIQUE                          |                   | 存档资源名称，一般为 hash 值和文件名不一致                |
   | asset_size    | INTEGER | NOT NULL                                 | 0                 | 逻辑资源大小 (字节),非实际占用 (压缩，加密会影响实际大小) |
   | asset_hash    | TEXT    | NOT NULL UNIQUE                          |                   | 存档资源的 hash 必须计算，否则后续要计算得先解档          |
   | asset_mtime   | INTEGER | NOT NULL                                 | 0                 | 修改时间 (unix 时间戳)                                    |
   | relative_path | TEXT    | NOT NULL                                 | './'              | 资源在存档内的相对路径                                    |
   | status        | TEXT    | NOT NULL                                 | 'HEALTH'          | 状态：HEALTH/CLOSED/RECYCLED/DRAFT                        |
   | created_at    | INTEGER | NOT NULL                                 | CURRENT_TIMESTAMP | 创建时间戳                                                |
   | updated_at    | INTEGER | NOT NULL                                 | CURRENT_TIMESTAMP | 更新时间戳                                                |

    - 由于文件添加到存档中一般不分层级，所以要求使用 id 或 hash 重命名文件，并存储到存档中，文件名要求唯一

8. 文件与存档资源表 file_volume_asset

    - 当文件体积过大被拆分时，一份文件可能对应多个存档和分卷资源。
    - 当文件重复时，一份资源可能对应多份文件。
    - 分卷是针对文件 file, 存档并不会识别出这个资源是分卷资源还是普通资源

   | 字段名       | 类型    | 约束                                  | 默认值            | 说明                         |
      | ------------ | ------- | ------------------------------------- | ----------------- | ---------------------------- |
   | id           | INTEGER | PRIMARY KEY AUTOINCREMENT NOT NULL    |                   |                              |
   | file_id      | INTEGER | NOT NULL REFERENCES file_index(id)    |                   |                              |
   | asset_id     | INTEGER | NOT NULL REFERENCES archive_asset(id) |                   |                              |
   | volume_order | INTEGER | NOT NULL                              | 1                 | 分卷顺序编号                 |
   | status       | TEXT    | NOT NULL                              | 'HEALTH'          | 状态：HEALTH/CLOSED/RECYCLED |
   | created_at   | INTEGER | NOT NULL                              | CURRENT_TIMESTAMP | 创建时间戳                   |
   | updated_at   | INTEGER | NOT NULL                              | CURRENT_TIMESTAMP | 更新时间戳                   |
