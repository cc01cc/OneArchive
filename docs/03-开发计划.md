# 1. 开发计划

## 1.1. 后端项目合并到 Tauri Rust 部分

扫描功能，主要校验的是数据库记录是否正确 (记录是否存在，记录的 status 是否正确)

### 1.1.1. 场景

1. 新的存档
2. 增量存档 (需要额外校验，被删除或修改的文件，对应记录是否删除或更新)
3. 已经存在若干个存档，再添加独立的新的存档
4. 两个包含关系的存档

### 1.1.2. 详细测试场景和预期结果

### 1.1.5. 扫描流程说明

扫描过程可以分为以下几个阶段：

1. **初始化阶段**
   - 查找或创建根目录记录
   - 将所有现有目录和文件标记为 WaitToDelete

2. **遍历阶段**
   - 遍历目录结构
   - 对于发现的目录和文件：
     - 如果已存在，根据情况更新状态
     - 如果不存在，创建新记录并设置为 UNARCHIVED

3. **结束阶段**
   - 保持根目录状态不变
   - 未被更新的记录保持 WaitToDelete 状态，表示已删除

### 1.1.6. 数据库操作验证点

在每个测试场景中，我们需要验证以下数据库操作点：

1. **根目录表 (info_root)**
   - 根目录记录正确创建
   - 根目录状态正确更新
   - 多个根目录之间互不干扰

2. **目录表 (info_directory)**
   - 目录记录正确创建
   - 目录状态正确更新
   - 父子目录关系正确维护

3. **文件表 (info_file)**
   - 文件记录正确创建
   - 文件状态正确更新
   - 文件与目录的关联关系正确

4. **视图 (view_file)**
   - 能正确查询文件及其目录信息
   - 状态过滤功能正常

### 1.1.7. 特殊情况处理

| 情况       | 描述                           | 处理方式                   |
| ---------- | ------------------------------ | -------------------------- |
| 长路径处理 | Windows 系统下的长路径前缀处理 | 自动识别并统一处理路径格式 |
| 权限问题   | 文件或目录访问权限不足         | 记录错误日志并跳过处理     |
| 符号链接   | 处理符号链接避免循环引用       | 检测并避免重复处理         |
| 大文件处理 | 大文件的哈希计算性能           | 异步处理并提供进度反馈     |

### 1.1.8. 已实现的测试用例

目前我们已经实现了以下测试用例：

1. **test_get_directory_statistics** - 测试目录统计功能
   - 基本目录结构统计
   - 空目录统计
   - 嵌套目录结构统计

2. **test_scan_and_save_directory_with_events** - 测试首次扫描功能
   - 验证新创建记录的状态为 UNARCHIVED
   - 验证数据库记录正确性

3. **test_incremental_scan_and_save_directory_with_events** - 测试增量扫描功能
   - 文件修改检测
   - 新增文件和目录处理
   - 文件删除标记处理
   - 状态正确性验证

4. **test_multiple_independent_roots** - 测试多个独立根目录处理
   - 验证多个根目录可以正确共存
   - 验证各根目录的数据隔离性

这些测试用例覆盖了开发计划中提到的主要场景，确保了扫描功能的正确性和稳定性。
